## 🌟 Overview

**WILT** turns fragmented notes and exam cramming into an engaging daily learning habit backed by spaced repetition and peer collaboration. 

Instead of passive 3-hour lecture slides, students write and read **30-second insights, formulas, and mental models** that immediately click.

---

## ✨ Key Features

- 📝 **Digital Notepad Slate (Landing Experience)**:
  - Focused distraction-free typing studio with rich text formatting, takeaway builders, and glossary term extraction.
  - **MS Word Style Mathematical & Financial Ribbon**: 40+ instant symbols ($\frac{a}{b}, \sqrt{x}, \sum, \int, \alpha, \beta, \sigma, \mu, \text{WACC, CAPM, EBITDA}$).
  - **ReactBits Masked Heading**: High-impact shimmering gradient title with dynamic hand-drawn SVG scribble sketch animations.
- 🛡️ **Source of Trust (Mandatory Verification)**:
  - Prevents misinformation by requiring either a Reference URL or a physical/course Learning Context (*"Seen on notice board"* / *"Prof. Miller's Lecture"*).
- 🚫 **Algorithmic Content Moderation**:
  - Automated scanner that immediately blocks profanity, harassment, and abusive language with clear guideline feedback.
- 🧠 **Weekly Spaced Recall Quiz**:
  - Automatically compiles 5 high-yield MCQs from peer posts without manual question authoring.
  - **"Did you forget about it? Read it here"** instant memory bridge linking directly back to the original source card when an answer is missed.
- 🏆 **Campus Rank Hierarchy**:
  - Gamified student standing (🥇 Gold, 🥈 Silver, 🥉 Bronze podiums, XP progression, and achievement badges).
- 📖 **Crowdsourced Peer Glossary**:
  - Searchable plain-English analogies for complex finance, banking, accounting, and computer science concepts.
- 📱 **Collapsible Sidebar & Smart Hamburger**:
  - `⌘B` / `Ctrl+B` toggle for 100% full-width immersive canvas reading.
- 📄 **Complete Policy & Legal Suite**:
  - Dedicated **Privacy Policy**, **Terms of Use**, and **Community Standards** opening in new tabs.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Mishra1208/WILT.git
cd WILT
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

## ☁️ Deploy to Vercel
